# 笔记模板

```markdown
# [主标题] 学习总结

**学习主题：** [主标题]
**学习时间：** YYYY-MM-DD

## 一、基础知识
1. XXX是什么（核心定义）
2. 为什么要用XXX（核心价值与意义）
3. 相似方案/产品对比分析
4. 是否存在更好的方法（优劣分析）
5. 典型使用场景
6. 一句话核心总结

## 二、常见问题QA
1. 对话中提出的所有问题及解答
2. 行业常见问题及标准解答
3. 面试高频问题及参考答案（AI生成，建议交叉验证）

## 三、使用与最佳实践
1. 具体使用方式与基本执行流程
2. 实操最佳实践与规范
3. 生产环境中评估是否使用的判断标准

## 四、思考与总结
1. 可扩展学习与应用的延伸点
2. 当前行业现状与发展趋势

## 五、参考链接
1. 官方网站地址
2. GitHub仓库地址
3. 权威最佳实践参考文章链接
```
